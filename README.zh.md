# content-writer

以研究為基礎的內容寫作夥伴，幫助您研究、概述、起草和精煉內容，同時保持您的獨特聲音。

## 概述

專注於創作具有引用來源的研究驅動型內容：
- 部落格文章和文章
- 電子報和思想領導力
- 案例研究和教學指南
- 附來源和引用的內容

## 工作流程

```
理解 --> 概述 --> 研究 --> 起草 --> 回饋 --> 潤色
  ^                         |
  +------- 逐節迭代 --------+
```

## 六個階段

1. **理解**：主題、受眾、格式、目標、長度、風格
2. **概述**：協作建立結構，標記研究空白
3. **研究**：搜尋相關、最新、可信的來源，記錄完整引用
4. **起草**：一次一節，獲取回饋後再繼續
5. **逐節回饋**：優點、建議、行文編輯、問題
6. **潤色**：最終檢查清單——引用、鉤子、過渡、語調

## 引用管理

支援三種格式（選擇一種，始終如一）：
- 行內引用
- 編號引用
- 腳注引用

## 後續步驟

潤色後，導出至：
- `/docx` — Word 格式
- `/pdf` — PDF 格式
- `/pptx` — 簡報格式
